Schéma de l'arborescence de navigation

Dix écrans, quatre onglets racine et deux écrans hors session. La profondeur maximale est de trois niveaux ; aucune action n'est accessible par un chemin dépassant trois gestes. Les liens profonds fonctionnent depuis une notification locale, donc également sans réseau.

Règles de navigation

  • La barre inférieure est visible sur les quatre onglets racine ; elle disparaît sur les écrans de formulaire et les feuilles modales.
  • Le retour utilise la flèche et le geste système, avec la même cible dans les deux cas.
  • Une sortie de formulaire non enregistrée déclenche un avertissement.
  • Toute action irréversible (suppression, effacement) exige une confirmation explicite.
  • Aucun écran n'est accessible par retour arrière depuis un état vide : la seule sortie est l'action proposée.
